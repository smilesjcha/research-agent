# Evidence Quality Rubric

| score | 기준 |
|---:|---|
| 5 | 원문 결과, 방법, 수치가 claim을 직접 지지하고 페이지가 확인됨 |
| 4 | 원문이 claim을 직접 지지하지만 세부 수치나 맥락 보강이 필요함 |
| 3 | 관련 논문이나 claim이 다소 넓거나 간접적임 |
| 2 | 주제는 비슷하지만 claim을 뒷받침하기에는 약함 |
| 1 | 인용하기 부적절하거나 원문 확인이 안 됨 |

## Evidence Type

- empirical_result
- systematic_review
- theory
- method
- design_principle
- background
