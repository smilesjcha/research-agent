## 카드 A · 직무 리서치 (채용공고 → 역량 매트릭스)

```text
01_jd 폴더의 채용공고 3개와 02_experience/경험정리.md를 읽고,
① 요구 역량 × 회사 표를 만들어줘. 각 칸은 필수 / 우대 / 언급 없음 중 하나로.
② 내 준비도 열을 상·중·하로 채우고, 근거 열에는 경험정리.md의 어느 항목을 근거로 했는지 적어줘.
③ 공고에 명시되지 않은 역량은 추측하지 말고 '확인 필요'로 표시해줘.
결과는 04_outputs/역량매트릭스.md 로 저장하고, 표 아래에 '가장 먼저 채울 빈칸 1개'를 이유와 함께 써줘.
```

후속 요청 (결과를 보며 한 가지씩)

| 상황 | 요청문 |
|---|---|
| 결과가 너무 길 때 | 표만 남기고 설명은 각 행 한 줄로 줄여줘. |
| 근거가 약할 때 | 준비도 '상'으로 표시한 행마다 경험정리.md의 원문을 인용해줘. 인용할 수 없으면 '중'으로 내려줘. |
| 다음이 안 보일 때 | '하'인 역량 하나(예: 빅데이터·머신러닝 데이터 분석)를 골라 4주 안에 증거를 만들 계획을 주차 · 목표 · 증거 · AI에게 맡길 것 · 내가 확인할 것 다섯 열로 써줘. 04_outputs/30일계획_데이터분석.md에 저장. |
| 검토를 받고 싶을 때 | 이 표를 채용 담당자 관점에서 보고, 근거가 부족해 보이는 칸 3개를 지적해줘. |

## 카드 B · 비판적 검토 (내 보고서)

```text
03_drafts/보고서.md를 처음 읽는 채용 담당 엔지니어 관점으로, 칭찬은 생략하고
① 논리 비약 ② 근거 없는 숫자 ③ 용어 불일치 ④ 독자가 모를 전제 ⑤ 빠진 한계
기준으로 문제 문장을 원문 인용 + 이유 한 줄 + 고친 예시 한 줄로 정리해줘.
가장 심각한 3개를 먼저, 확신 없는 지적은 '확인 필요'로. 결과는 04_outputs/검토_보고서.md 에 저장.
```

후속 요청

| 상황 | 요청문 |
|---|---|
| 지적이 뭉뚱그려질 때 | 문장 단위로 원문을 인용해줘. |
| 반박하고 싶을 때 | 2번 지적은 측정 로그(3회 반복, ±2%p)가 있어. 이 근거를 반영하면 지적이 유지되는지 다시 판단해줘. |
| 다시 쓰고 싶을 때 | 내가 고친 문장이야: "…". 다섯 기준으로 다시 봐줘. 대신 써 주지는 마. |

## 카드 C · 모의 면접

```text
02_experience/경험정리.md와 03_drafts/자소서.md를 읽고,
경험 검증 · 기술 깊이 · 협업 · 실패·한계 네 유형으로 예상 질문 10개를 만들어줘.
내가 답하면 답마다 꼬리질문 하나와, '구조(문제·제약·결정·결과·배움)'와 '근거(숫자·출처)' 두 기준의 피드백만 짧게 해줘.
질문 목록은 04_outputs/면접질문.md 에 저장. 답변 대신 써 주지 마.
```

답변 예시 (소리 내어 말한 뒤 요약해서 입력)

```text
C1에 답할게. 처음 계획은 새 증류 장치를 만들고 자동 온도 제어까지 넣는 거였는데, 4명, 8주, 예산 30만원에 인화성 규정으로 야간 실험이 안 돼서 다 못 한다고 봤어. 두 명은 장치 제작을 꼭 하고 싶어 했어. 나는 '기존 증류기에서 환류비와 온도 두 조건만 먼저 검증하고, 4주 실제로 운용해서 회수율이 오르면 그때 장치를 만들자'고 제안했고, 4주 운용 조건은 내가 걸었어. 결국 회수율이 40%에서 72%로 올랐고 폐용매가 주 20L에서 6L로 줄었어.
```
