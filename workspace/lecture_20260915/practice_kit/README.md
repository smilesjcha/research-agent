# 실습 키트 — my-career (PNU 공학커뮤니케이션 2026-09-15)

취업 준비 문서를 Claude Code로 다루는 실습용 프로젝트입니다. 자료가 없어도 예시 파일로 바로 시작할 수 있습니다.

## 시작하기 (3분)

1. 이 저장소를 내려받는다. (GitHub → Code → Download ZIP, 또는 `git clone`)
2. **Claude Desktop** 실행 → 왼쪽 상단 **Code** 탭 → **폴더 열기** → `practice_kit/my-career` 선택
3. **새 세션** → 모델 **Claude Fable 5.1** · 노력 수준 **높음**
4. `../prompt_cards.md`의 카드 A를 그대로 붙여 넣는다.
5. 결과는 `my-career/04_outputs/`에 파일로 생긴다. 표의 행마다 **확인 완료 / 확인 필요**를 직접 표시한다.

## 폴더

```text
my-career/
├─ CLAUDE.md          Claude가 세션마다 먼저 읽는 규칙 (확인 필요 · 출처 · 대신 쓰지 않기 · 04_outputs에만 저장)
├─ 01_jd/             예시 채용공고 3개 (반도체 공정 · 배터리 셀 설계 · 로봇 SW) — 본인 공고로 교체 가능
├─ 02_experience/     경험정리.md — 경험 × (문제 · 제약 · 결정 · 결과 · 배움)
├─ 03_drafts/         보고서.md, 자소서.md — 일부러 고칠 곳을 남긴 예시
└─ 04_outputs/        AI 결과 파일 (여기에만 저장, 덮어쓰기 금지)
```

## 내 자료로 바꾸기

- `01_jd/`에 지원할 공고를 Markdown 또는 PDF로 넣는다. (3개 이내)
- `02_experience/경험정리.md`를 본인 경험으로 다시 쓴다. 모르는 칸은 비워 둔다. AI가 질문으로 채운다.
- `03_drafts/`에 본인 보고서·자소서·README를 넣는다.

## 넣지 말아야 할 것

연구실·인턴 회사의 비공개 자료, 타인의 개인정보가 든 파일. 필요하면 식별 정보를 지운 요약본만 넣는다.

## 실제 실행 결과 보기

강사가 같은 카드를 Claude Code(Fable 5.1 · 높음)로 실행한 결과가 `../practice_runs/outputs/`에, 세션 화면이 강의 PPT 37~45번 장표에 있습니다. 내 결과와 비교해 보세요.
