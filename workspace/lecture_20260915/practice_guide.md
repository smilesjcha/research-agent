# 실습 시뮬레이션 가이드 — Claude Code로 카드 A · B · C 직접 돌려 보기

강사가 강의 전에 혼자 리허설하거나, 강의 중 시연할 때 그대로 따라 하는 순서입니다.
학생 배포용 요약은 `practice_kit/README.md`, 요청문 원문은 `prompt_cards.md`에 있습니다.

## 0. 준비 (강의 전 1회, 5분)

1. 저장소를 내려받는다.
   ```bash
   git clone https://github.com/smilesjcha/research-agent.git
   ```
2. Claude Desktop 실행 → 왼쪽 상단 **Code** 탭 → **폴더 열기** → `research-agent/workspace/lecture_20260915/practice_kit/my-career` 선택.
   - 이 폴더의 `CLAUDE.md`가 세션마다 자동으로 읽힌다. (확인 필요 표기 · 04_outputs에만 저장 · 대신 쓰지 않기)
3. **새 세션** → 입력창 아래 모델 메뉴에서 **Claude Fable 5.1**, 노력 수준 **높음**을 고른다.
4. `04_outputs/`가 비어 있는지 확인한다. (지난 실행 결과가 있으면 `_v2`로 저장되므로 비교용으로 남겨도 된다.)

## 1. 실습 A · 직무 리서치 (세션 1개, 두 턴)

| 턴 | 내가 입력하는 것 | Claude가 하는 일 (실제 실행 기록 기준) | 내가 확인할 것 |
|---|---|---|---|
| 1 | 카드 A 원문 그대로 | `01_jd/`의 삼성전자 DS · LG에너지솔루션 · 한화에어로스페이스 공고 요약 3개 + `경험정리.md` Read → `04_outputs/역량매트릭스.md` Write. 13행 × 3사 표, 준비도, '가장 먼저 채울 빈칸 1개' | 각 칸에 공고의 어느 섹션(자격 요건 · 수행업무 · 우대)에서 옮겼는지 적혔는가 · 전공·어학처럼 사실이 없는 칸이 '확인 필요'인가 · 근거 열이 경험정리의 어느 칸을 가리키는가 |
| 2 | `'하'인 역량 #8(빅데이터·머신러닝 데이터 분석)을 골라 4주 계획을 주차·목표·증거·AI에게 맡길 것·내가 확인할 것 다섯 열로 써줘. 경험 2의 측정 로그 CSV와 Python 스크립트에서 출발해줘. 04_outputs/30일계획_데이터분석.md에 저장.` | `30일계획_데이터분석.md` Write. AI가 맡을 것과 본인이 확인할 것을 열로 분리 | 표의 마지막 두 열이 18번 장표(30일 준비 계획)와 같은 구조인지 |

대체 후속 요청 (시간이 남을 때): `준비도 '중'인 행마다 경험정리.md 원문을 인용해줘. 인용할 수 없으면 '하'로 내려줘.`

## 2. 실습 B · 비판적 검토 (세션 1개, 두 턴)

| 턴 | 내가 입력하는 것 | Claude가 하는 일 | 내가 확인할 것 |
|---|---|---|---|
| 1 | 카드 B 원문 | `보고서.md` + `경험정리.md` + 삼성전자 DS 직무소개 Read → `04_outputs/검토_보고서.md` Write. 가장 심각한 3개 + 나머지 16개, 경험정리(개인)와 보고서(조원과 함께)의 충돌은 '확인 필요' | 원문 인용이 문장 단위인가 · '확인 필요' 표시가 있는가 · 고친 예시에 새 숫자를 지어내지 않았는가 |
| 2 | `지적 중 '80°C 수율 약 71%'에 근거가 없다는 항목은 반박할게. 측정 로그 CSV에 3회 반복 값이 있고 평균 71%, 편차 ±2%p, 대조군(60°C) 59%야. 이 근거를 반영하면 그 지적이 유지되는지 다시 판단해 주고, 유지된다면 문장을 어떻게 고쳐야 근거 사슬이 이어지는지 조건만 알려줘. 대신 써 주지는 마.` | '근거 없는 숫자' 분류는 철회하되 '근거가 보고서 안에 연결돼 있지 않다'로 라벨을 바꿔 유지. CSV를 못 봤으므로 표지 '요약만 확인'. 문장은 쓰지 않고 조건 8개만 제시, 파일은 수정하지 않음 | AI가 지적을 철회하지도 고집하지도 않는가 · '대신 써 주지 마'를 지켰는가 |

학생 발표 포인트: 지적 3개를 **수용 / 반박(근거) / 확인 필요**로 나누고, 수용한 것 1개를 본인 문장으로 고친다.

| 3+ | 꼬리질문에 다시 답한다 | 같은 형식 반복 | — |

## 4. 강의 중 시연이 막혔을 때

- 네트워크·로그인 문제: PPT 37~45번 장표(실제 실행 화면)로 대체 시연. 화면은 `practice_runs/transcripts/`의 실제 세션 기록을 렌더링한 것이다.
- 결과가 너무 길다: `표만 남기고 각 행 한 줄로 줄여줘.`
- 파일 쓰기 승인 창이 뜬다: Code 탭은 파일 생성 전에 승인을 묻는다. 경로가 `04_outputs/`인지 보고 승인.
- 학생 자료가 없다: 키트의 예시 파일로 그대로 진행한다. 예시임을 반드시 말한다.

## 5. 리허설 결과 재현 (터미널, 선택)

Claude Desktop에 번들된 Claude Code를 헤드리스로 돌려 같은 카드를 실행한 스크립트가 `practice_runs/run.sh`다.

```bash
cd workspace/lecture_20260915/practice_runs
./run.sh A1 A1.txt            # 카드 A 첫 턴
./run.sh A2 A2.txt <session>  # 같은 세션에 후속 요청 (session_id는 A1.json에 있음)
```

세션 화면 이미지는 `source/render_session.js`가 세션 기록(JSONL)에서 만든다. 실제 Claude Desktop 창을 캡처해 `assets/practice_A.png` 등으로 덮어쓰고 `node build.js`를 다시 돌리면 PPT의 화면도 바뀐다.
