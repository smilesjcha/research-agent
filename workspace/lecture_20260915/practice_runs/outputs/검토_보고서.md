- [ ] 60°C, 70°C 조건의 실제 수율 값 (측정 로그 CSV)
- [ ] 80°C 값이 "70% 이상"인지 "71%"인지, 그리고 그 값이 3회 평균인지 단일 값인지
- [ ] 경험정리의 "대조군 대비 12%p"에서 대조군이 60°C인지 70°C인지
- [ ] 조건당 반복 횟수와 시편 수, 표준편차 또는 최소·최대 값
- [ ] 고정한 압력 값과 단위
- [ ] "PJ 장비"의 정식 명칭과 공정 종류
- [ ] 수율의 정의 (양품 판정 기준, 분모)
- [ ] 고찰의 "반응"이 구체적으로 어떤 반응 또는 공정 단계인지
- [ ] 자동화 스크립트 측정값을 수동 측정과 비교 검증했는지
- [ ] 온도가 설정값인지 실측값인지, 실측 편차
- [ ] 실험이 "개인" 실험인지 "조원과 함께"인지, 조원의 실제 역할 (경험정리와 보고서가 다름)
