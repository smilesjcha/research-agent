## 실제 시연 4 — Research-agent 연구 과정

### 준비

```bash
git clone https://github.com/smilesjcha/research-agent.git
cd research-agent
pip install -r requirements.txt
jupyter notebook
```

### 진행 순서

1. `notebooks/00_topic_scoping.ipynb`
   - 연구질문, 검색어, 기간, 검색 필드를 하나의 계약 파일로 저장한다.
   - `data/topic_keywords.txt`가 만들어지는 것을 확인한다.
2. `notebooks/01_search_papers.ipynb`
   - OpenAlex 호출 코드에서 검색식, 검색 조건, 페이지 이동 방식, 실행일을 짚는다.
   - `data/papers_raw.csv`와 `data/search_strategy.md`를 확인한다.
3. `notebooks/02_score_quality.ipynb`
   - 점수는 ‘정답’이 아니라 선별 우선순위임을 강조한다.
   - `git diff -- notebooks/02_score_quality.ipynb`로 변경을 확인한다.
4. `notebooks/03_export_to_claude.ipynb`
   - 상위 15편을 구조화된 Markdown으로 내보낸다.
   - 원문 확인 전에는 핵심 인용으로 확정하지 않는 문구를 확인한다.

### 실패를 가르치는 데모

`02_score_quality.ipynb`의 word-boundary 정규식에 보이지 않는 제어문자가 들어가면 `AI` 단독 키워드가 탐지되지 않을 수 있다. “코드가 실행됨”과 “의도대로 작동함”은 다르다는 것을 보여주고, 다음 불변조건을 테스트로 바꾼다.

```python
assert keyword_hits({'title': 'AI tutoring', 'abstract': ''}) == ['AI']
```
