# References

논문 PDF, 메타데이터, reading note, evidence table을 저장하는 공간입니다.

## PDF 저장 규칙

1. 새 PDF는 `references/pdfs/00_inbox/`에 둡니다.
2. 읽고 분류한 뒤 아래로 이동합니다.
   - `10_core`
   - `20_supporting`
   - `30_background`
   - `90_excluded`
3. 파일명은 가능하면 `YYYY_FirstAuthor_short-title.pdf`로 통일합니다.
